# Identification of the Algorithm from the Given Dataset using AIML Techniques

## Abstract
Selecting the most suitable machine learning algorithm for a dataset is a challenging task. 
This project proposes a system that automatically identifies the best algorithm for a given dataset 
using Artificial Intelligence and Machine Learning techniques. The system extracts meta-features 
from datasets and recommends appropriate algorithms based on performance patterns. 
It helps users choose efficient algorithms without manually testing multiple models.

## Technologies Used
- Python
- Flask
- Machine Learning
- Pandas
- Scikit-learn

## Features
- Dataset upload
- Feature extraction
- Algorithm recommendation
- Performance analysis

## How to Run
1. Install requirements
2. Run `python app.py`
3. Open `http://127.0.0.1:5000`
